# OpenClaw runtime config

This tree holds runtime-local OpenClaw configuration, agent templates, skills wiring, and workspace-specific instruction material.

## This tree owns

- agent template files
- workspace-local instruction sets
- runtime identity and settings
- runtime-local skills and subagents

## This tree does not own

- repo-wide architecture
- product launch scope
- stable repo engineering standards

Those belong in root docs and `docs/`.

## Important boundary

Do not keep duplicate workspace persona files at repo root. Runtime-local persona and memory templates belong here.
