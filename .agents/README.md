# .agents

This directory is an optional skill library and helper surface for agent runtimes.

## What belongs here

- reusable skill packs
- model helper material
- task-specific spawn guidance

## What does not belong here

- repo-wide architecture truth
- current product scope
- runtime source of truth
- duplicate bootstrap instructions that belong in root docs

## How to use it

Read files here only when the task clearly needs them.

Default bootstrap remains:

1. `AGENTS.md`
2. `README.md`
3. `docs/README.md`
4. nearest owning `README.md`
