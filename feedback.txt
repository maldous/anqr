A few tweaks I’d suggest:

1) Make “public API” explicit per module
- Keep src/modules/<mod>/index.ts as the only public surface.
- Everything else lives under src/modules/<mod>/internal/* (or similar).
- This prevents “just import that helper” creep.

2) Add dependency rules now (or you will regress)
- core: no deps
- qr-spec: only core
- qr-encoder/qr-decoder: only core + qr-spec (+ their own internals)
- shared/common: only if it’s truly cross-cutting, otherwise delete it
Implement with an ESLint import boundary rule or TS project refs.

3) Be careful with “shared/”
If shared contains *domain* things (patterns, masks, RS/BCH helpers, etc), it belongs in qr-spec.
If shared contains *pipeline* things (instrumentation, I/O, worker glue), it belongs in platform/ or a “pipeline/” module.
Goal: shared should trend toward empty.

4) Keep image concerns separated from QR-domain concerns
- qr-spec should not know ImageData, pixels, canvases, etc.
- decoder can accept “matrix/bit grid” inputs, and image->matrix lives in analyzer/pipeline.
This keeps the spec reusable and testable.

5) Canonicalization needs tests (or you’ll break subtle behavior)
Before moving duplicated funcs (rgbToGrey, clamp, getContrastRatio, patterns), add a small golden test suite.
Then move code. Then delete duplicates.

6) Avoid barrel-export performance traps
Index files are fine, but avoid huge `export *` chains across many modules.
Prefer explicit named exports for hot code paths.

7) Migration strategy improvement
- First: introduce new modules and re-export from old paths for compatibility.
- Only later: flip imports across the codebase.
This keeps PRs small and bisectable.


If you want one concrete “rule of thumb” to keep it clean:

If a function is needed by both encoder + decoder, it belongs in qr-spec (domain) or core (generic).
If it touches pixels, files, canvas, DOM, or Node APIs, it belongs outside qr-spec/core.


Net: I’d keep your structure, add “internal/ + boundary enforcement”, and aggressively prevent shared from becoming a junk drawer.
