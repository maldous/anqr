# Payload Verification Matrix

This report tracks payload-kind coverage across UI selectors and generator outputs.

## Generate

- Command: `npm run report:payload:matrix`
- Typical outputs:
  - `reports/payload-verification-matrix.md`
  - `reports/payload-verification-matrix.json`

## Intent

- Detect selector/generator drift.
- Confirm each supported payload kind has a passing validation row.
