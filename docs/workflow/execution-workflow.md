# Execution Workflow

This workflow defines the operating sequence for implementation sessions.

1. Identify ticket state and route by state.
2. Reconcile the persistent workpad comment before new edits.
3. Capture baseline/reproduction evidence.
4. Sync repository state with `origin/master`.
5. Implement against a hierarchical checklist.
6. Run targeted validation for changed scope.
7. Reconcile acceptance criteria and validation notes.
8. Keep issue metadata and review artifacts current.

For legacy entry points, see [`../../WORKFLOW.md`](../../WORKFLOW.md).
