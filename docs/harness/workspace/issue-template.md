# ANQR Issue Template

Use this as the canonical starting structure for active implementation issues.

## Summary

One-sentence outcome.

## Scope Class

Examples:

- `docs-harness`
- `product-web`
- `api-mcp`
- `core-packages`
- `mobile`
- `ops-incident`

## Owned Surfaces

- projects
- labels
- runtimes

## Constraints

- architecture
- privacy
- cost
- human-only
- launch-claim

## Definition Of Done

- concrete expected end state
- exact gates to run
- exact evidence required

## Verification

```bash
<commands>
```

## Evidence Payload

- Summary
- Scope class
- Touched paths
- Decisions made
- Commands run
- Pass/fail result for each command
- Changed files
- Commit hash
- Issue comment text
- Artifacts attached or linked
- Risk / rollback note
- Follow-up work

## Escalate If

- paid spend is required
- prod auth/privacy posture changes are required
- store or signing work is required
- operator secret access is required
- launch scope is being reduced or expanded
