# Agent-First Harness Model

## Principles

- Keep `AGENTS.md` short and map-oriented.
- Keep deep knowledge in `docs/` with explicit ownership.
- Prefer deterministic validation and reproducible evidence over informal notes.

## Documentation Policy

- New durable guidance goes into `docs/`.
- Legacy markdown files are reduced to pointer stubs.
- Historical logs stay in `docs/archive/`.
- Report files in `reports/` may remain as compatibility entry points, but canonical report definitions live in `docs/reports/`.

## Verification Policy

- Verify file existence and link topology after structural moves.
- Reconcile legacy paths against canonical docs using the matrix in `docs/inventory/markdown-reconciliation.md`.
- Preserve immutable references (`ISO_IEC_18004_2015.md`).
